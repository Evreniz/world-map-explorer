# World Terrain Atlas

This repository contains a multi-layer world map prototype for terrain exploration, topography, geology, and underground overlays.

## Included
- world map with satellite/base map switching
- cities and mountain markers
- fault line overlay
- geology zones
- underground exploration layer
- focus buttons for key regions
- toggles for visibility of each layer

## Run locally
Open `index.html` in a browser, or serve the repository with a small static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
This is a prototype designed to be extended with real DEM datasets, geographic geology layers, and a 3D terrain view.
